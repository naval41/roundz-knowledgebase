## 5. Pre-Written PH Comment Responses

### "How is this different from HackerRank?"

```
Great question! HackerRank tests if someone can solve a coding puzzle. Roundz tests if someone can actually think through a problem out loud — the way a real interview works. We use voice AI that asks follow-up questions, probes reasoning, and evaluates communication. Plus we cover the full loop (DSA + System Design + LLD + Behavioral) not just one round.
```

### "Does this replace human interviewers?"

```
Not at all — it replaces the screening rounds that burn 80% of engineering time. Think of it as a pre-filter: AI handles the first 3-4 rounds, then humans only talk to the top 20% who are actually worth their time. The final decision is always human.
```

### "How do you handle cheating/AI-assisted answers?"

```
This is something we obsess over. We have real-time proctoring — face detection, gaze tracking, keyboard monitoring — that catches AI-assisted cheating with 92% accuracy. If someone's reading from ChatGPT, we know. Honest candidates actually love this because it levels the playing field.
```

### "What's the pricing?"

```
We charge per candidate screened (credit-based). For PH community, we're offering a free demo — screen your first candidates at no cost so you can see the quality of evaluations before committing. Happy to set you up if you're interested!
```

### "Interesting!" / Generic praise

```
Thanks! Curious — what does your current interview process look like? Always interested to hear what's working (and what's painful) for different teams.
```

### "Looks cool but we're too small/early"

```
Totally get it. Honestly this hits hardest when you're at that 50-200 engineer stage where every hire matters but the founding team can't interview everyone anymore. Happy to chat whenever you hit that point — the free demo doesn't expire!
```
