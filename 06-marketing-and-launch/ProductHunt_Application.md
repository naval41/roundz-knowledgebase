## 8. Product Overview (For Reference in Comments)

### How It Works (The 80/20 Model)
1. Recruiter posts a job → AI enriches skill requirements
2. Candidates apply → AI matches resumes semantically (not keyword matching)
3. Top matches (~40%) are shortlisted by match score
4. AI Voice Agent conducts interviews: DSA, System Design, LLD, Behavioral
5. Real-time proctoring: face detection, gaze tracking, clipboard monitoring
6. AI generates full evaluation: strengths, growth areas, hire/no-hire verdict with reasoning
7. Top 20% of pre-vetted candidates presented to hiring team
8. Hiring manager makes the final call (human-in-the-loop)

### Tech Stack Highlights (For HN/Developer Audiences)
- Voice AI: Pipecat AI + Daily.co WebRTC
- Code Editor: Monaco Editor (50+ languages)
- Whiteboard: Excalidraw (system design)
- AI Evaluation: AWS Bedrock (Claude)
- Proctoring: MediaPipe Vision (face detection, gaze tracking)
- Frontend: Next.js 14, React 18, TypeScript, Tailwind
- Backend: Node.js, Express, PostgreSQL (Prisma)

### Interview Types
- Data Structures & Algorithms (DSA) — 60 min, live coding
- Low-Level Design (LLD) — 60 min, OOP/SOLID/patterns
- High-Level Design (HLD) — 60 min, architecture + whiteboard
- Behavioral — communication, leadership, conflict resolution
