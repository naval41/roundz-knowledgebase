# 04 - Sales Toolkit

The hands-on kit for running the founder-led sales motion. All current, all built on the narrative in `../03-sales-pitch`.

| File | What it is | When you use it |
|---|---|---|
| [`Cold_Outreach_Cadence_and_ICP.md`](Cold_Outreach_Cadence_and_ICP.md) | Demand-signified ICP, list sourcing, multi-touch cadence, and ready-to-send email/LinkedIn/call/voicemail templates | Top of funnel: getting the meeting |
| [`Discovery_and_Demo_Script.md`](Discovery_and_Demo_Script.md) | Pre-call plan, up-front contract, discovery questions, section-by-section demo, live ROI math, the ask | The sales call itself |
| [`One_Pager.md`](One_Pager.md) | Scannable leave-behind for a CTO/VP Eng | Send before/after a call |
| [`Pilot_Offer_and_Pricing.md`](Pilot_Offer_and_Pricing.md) | The de-risked-but-priced one-req pilot, value-based pricing, credit-pack packaging, negotiation | Closing / converting |
| [`Objection_Handling_Playbook.md`](Objection_Handling_Playbook.md) | Acknowledge, Clarify, Reframe, Confirm, Advance across 7 objection categories | Prep and live reference |
| [`Founding_Sales_Playbook_Notes.md`](Founding_Sales_Playbook_Notes.md) | Distilled Peter Kazanjy method (the "why" behind the whole toolkit) | Reference / onboarding |

**Funnel:** ICP + list, cold cadence, discovery + demo (one-pager as leave-behind), priced pilot (objections handled throughout), convert to credit pack / subscription, first case studies replace industry-research proof with our own numbers.
